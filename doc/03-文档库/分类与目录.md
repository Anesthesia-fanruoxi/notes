# 分类与目录

## 结构

- 分类是树：`Category { id, name, parentId, order }`，存于 `library/index.json`。
- 内置一个不可删改的「未分类」（id = `uncategorized`），新建文档默认落这里；删除目录时其中的文档也会回落到未分类。
- 侧栏按 `order` 再按名称排序；每个分类行显示**本层**文档数（不含子目录）。

## 侧栏交互

- 折叠/展开：点击分类行左侧的方框 `+/−` 或整行；展开时方框变为强调色。折叠状态只存内存（重启复位）。
- 整个文档库侧栏可收起为 34px 窄条；收起/展开有宽度、内容淡出和窄条淡入的过渡，拖动分隔条调整宽度时关闭过渡，保持跟手。
- 新建：
  - 顶部「常驻文档」右侧 `＋` 或空白处右键 → 新建文件 / 新建目录 / 导入文件…
  - 分类行右侧 `＋` → 在本目录新建文件 / 子目录。
  - 新建文件默认扩展名 `.txt`；侧栏显示完整文件名（含后缀），标题左侧预留未保存黄点位置，右侧末尾显示按格式着色的类型徽标；无后缀时徽标显示 `-`，不再额外显示「文件」字样。
- 重命名 / 删除：
  - 右键分类 → 重命名、删除（内置「未分类」禁用这两项）。
  - 删除前提示：子目录内 `N` 篇文档会移到「未分类」，不会被删除。
- 拖动：
  - 文档可拖到任意分类行（含折叠的），松开即移动分类。
  - 有搜索词时拖动语义变为「移动到分类」，平时拖动只挂高亮。

## 文档行

- 显示标题、AI 可读锁标记、已修改点。
- 双击 / 单击打开（见《快速打开》）。
- 右键：重命名、移动到分类、版本、删除、AI 可读开关。
- 删除：文档文件进系统回收站；回收站不可用时移到应用数据目录的 `trash/`，并弹提示说明没有丢失。
- 若该文档正开着标签，删除时标签会一起关闭，对应 recovery 草稿失效。

## 空状态

- 「常驻文档」为空且只有内置「未分类」时显示引导：「文档库为空。右键或点 ＋ 新建第一个文档。」
- 只要存在自建目录或任何文档，引导就不再出现。

## 已知待打磨

- 折叠状态不持久化。
- 拖拽改分类没有「移到根级」的明确落点。
- 分类计数不统计子目录，深层结构下数字会看起来偏小。
