# 导入导出与备份迁移

## 导入（进文档库）

- 入口：侧栏空白右键 →「导入文件…」，或设置页/启动流程中的导入入口。
- 选文件后可逐个指定目标分类（默认未分类），确认后由 Rust 统一复制进 `library/docs/` 并写索引。
- 报告：成功数量、重名自动改名、跳过的文件（二进制/超限）。
- 导入的文档算常驻文档，不产生临时记录。

## 导出（导出副本）

- `Ctrl+Shift+S`：对常驻文档弹目录选择，把当前库内文件复制成 `<标题>.<扩展名>` 到目标目录。
- 导出的是**已保存的正文**；如果编辑器里有未保存改动，需要先 `Ctrl+S`。
- 临时文档没有导出副本入口（本身就在磁盘上或可直接另存进库）。

## 备份

- 设置页「文档库 → 备份」：选择目标目录，整个 `library/` 复制为 `NoteLibrary-<时间戳>`。
- 复制完成后会读一次目标索引做校验，失败即报错。
- 备份不包含 recovery 草稿、scratch 临时文件、AI 用量记录。

## 恢复

- 选择备份目录 → 先校验索引 → 把当前库另存为 `library.bak-<时间戳>` → 整体覆盖当前库。
- 恢复后建议重启应用，让前端重新加载索引与文档。

## 迁移库位置

- 选择新目录 → 复制到 `<新目录>/NoteLibrary`（要求目标为空）→ 校验索引 → 写入 `library-path.txt`。
- 旧库默认保留不删除，确认无误后可手动清理。
- 迁移后 recovery / scratch / usage 仍留在应用数据目录，不跟随。

## 已知待打磨

- 备份/恢复没有进度条，大库（上万文档）时界面会静默等待。
- 恢复不自动重启，只提示用户。
- 导出副本不更新文档库内文件，也不感知外部改动。
