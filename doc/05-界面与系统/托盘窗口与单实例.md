# 托盘窗口与单实例

## 窗口状态

- 启动时恢复上次的大小、位置、最大化状态（`tauri-plugin-window-state`）。
- 尺寸/位置变化与关闭请求后防抖 500ms 写一次状态，即使进程被强杀也能恢复到最近的尺寸。
- 不记忆「是否可见」：关闭到托盘时窗口是隐藏的，如果记住可见性会导致下次启动看不到窗口。

## 关闭到托盘

- 默认点关闭按钮 = 隐藏窗口、留在托盘；可在设置 → 通用里改成「关闭即退出」。
- 隐藏前会把所有未保存内容落快照（不弹确认）。
- 改成退出时，关闭按钮走退出流程：落快照 → `app.exit(0)`。

## 托盘

- 左键单击托盘图标：显示/隐藏主窗口。
- 右键菜单：显示主窗口 / 新建文档 / 退出。
- 「新建文档」会创建临时文件（同 `Ctrl+N`）。

## 单实例

- 再次启动进程时不会开第二个窗口：聚焦已有窗口，并把命令行里的文件路径通过 `cli://open` 事件转发给前端打开。

## 全局快捷键

- 默认 `Ctrl+Alt+N`，在设置 → 快捷键里修改。
- 任意应用在前台时按下都能唤起窗口；被其它程序占用时注册失败会有提示，换一个组合即可。

## 拖放与命令行

- 把文件拖进窗口：按「拖入文件」处理，作为临时文档打开并记录路径。
- 用本应用打开文件（关联/命令行）：同样作为临时文档打开；应用未启动时会随启动一起处理。

## 退出

- 退出前统一给所有标签落快照（临时 → scratch，常驻 → recovery），不弹确认，然后退出进程。
- 下次启动侧栏恢复临时记录，常驻文档点开时自动接着未保存的草稿。

## 已知待打磨

- 托盘菜单固定三项，不能自定义。
- 没有「开机自启」开关。
- 单实例转发只处理文件路径，不处理其它参数。
