# 设置页

## 外观

- 弹窗尺寸：宽 65vw、高 70vh，最小 600×460，最大 1180×88vh，随窗口自适应。
- 左侧导航 + 右侧内容区，内容区独立滚动。

## 分区

| 分区 | 内容 | 生效方式 |
| --- | --- | --- |
| 通用 | 主题（9 套，含护眼绿/暖米色/雾蓝/豆沙粉）、关闭窗口时收进托盘 | 立即生效并保存 |
| AI | 服务模板页签、Base URL、API Key、模型、计费、Temperature、请求范围、测试连接 | 改动先入草稿，右下角「保存」统一落盘 |
| 用量 | AI 调用统计面板（见《用量统计》） | 只读 |
| 编辑器 | 字体（16 套免费/开源及系统预设，状态栏也可左键切换/右键选择；只引用系统字体）、字号（8–32，默认 13；状态栏也可快速选择）、行高、编辑区背景预设/自定义颜色 | 立即生效并保存 |
| 文档库 | 篇数/分类数/正文占用、存储占用（源文件 / 快照 / 版本 / AI 记录 / 回收站，只读）、备份到文件夹、从备份恢复、更改库位置 | 统计与动作即执行 |
| 快捷键 | 全局唤起快捷键输入框 + 应用到默认、快捷键一览表 | 点「应用」生效 |
| 使用说明 | 文件 / 快照关系、未保存改动标记、列选择、换行符、文件打开方式速查 | 只读 |

## AI 分区的显式保存

- 所有 AI 字段（模板、地址、Key、模型、计费、Temperature、范围）都只改草稿。
- 底部左侧显示「AI 配置有改动未保存」，右侧「保存」主按钮；未改动时置灰。
- 保存时：Key 若已填写先写入凭据管理器（失败单独提示），再保存配置并通知 AI 面板重新读取。
- 未点保存直接关闭，草稿丢弃。

## 快捷键分区

- 全局唤起默认 `Ctrl+Alt+N`，格式如 `Ctrl+Alt+N`；被系统/其它程序占用时可能注册失败，换组合即可。
- 下方列出全部内置快捷键（与《快捷键总表》一致）。

## 使用说明分区

- 面向用户的速查：源文件 / 工作副本 / 快照的关系、行号后的改动标记、Alt/Ctrl 列选择、换行符切换、文件打开方式。
- 完整按键仍在「快捷键」分区；这里只解释功能怎么用。

## 已知待打磨

- 只有 AI 分区是显式保存，其它分区改动即生效，两套心智模型并存。
- 快捷键分区不能逐项改键，只能改全局唤起。
- 设置窗口本身不能调整大小。
