# 快捷键总表

## 应用内

| 快捷键 | 行为 | 触发范围 |
| --- | --- | --- |
| `Ctrl+N` | 新建临时文件（同时生成侧栏记录） | 全局 |
| `Ctrl+O` | 打开文件（作为临时文档） | 全局 |
| `Ctrl+S` | 常驻文档写回正文；有源文件的临时文档写回原文件；`+` 新建的临时文档弹「保存到文档库」 | 全局 |
| `Ctrl+Shift+S` | 导出副本（常驻文档） | 全局 |
| `Ctrl+W` | 关闭当前标签（不删内容，只收起视图） | 全局 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 | 全局 |
| `Ctrl+F` / `Ctrl+H` | 查找 / 替换 | 全局 + 编辑器 keymap |
| `Ctrl+P` | 快速打开（库 + 已打开的临时文档，按标题匹配） | 全局 |
| `Ctrl+,` | 打开设置 | 全局 |
| `Ctrl+/` | 注释 / 取消注释（交给 CodeMirror，Markdown 用 `<!-- -->`） | 编辑器 |
| `Ctrl+Shift+V` | Markdown 预览 / 源码切换（只读预览，仅 `.md`） | 全局（仅 md 标签响应） |
| `Ctrl+Shift+/` | 开关 AI 侧栏 | 全局 |
| `Esc` | 关闭当前浮层 / 面板 / AI 侧栏 | 全局 |

## 全局（系统级）

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl+Alt+N`（可改） | 任意应用在前台时唤起窗口 |

## 编辑器内（CodeMirror 默认）

- `Ctrl+Z` / `Ctrl+Shift+Z`：撤销 / 重做（AI 应用后可用 `Ctrl+Z` 一次撤销）。
- `Tab` / `Shift+Tab`：缩进 / 反缩进。
- `Ctrl+F` 之外的默认键位沿用 `@codemirror/commands`。

## 说明

- 输入法组合中（`view.composing`）一律放行，避免抢输入。
- 有弹层（设置、确认框等）时全局快捷键让路。
- `Ctrl+Shift+V` 在 Markdown 标签里不再执行「纯文本粘贴」；其它文件仍保留该行为。
- 修改全局唤起：设置 → 快捷键 → 输入组合 → 「应用」。
