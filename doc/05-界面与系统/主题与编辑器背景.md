# 主题与编辑器背景

## 全局主题

- 九套：跟随系统 / 浅色 / 深色 / 护眼绿 / 暖米色 / 雾蓝 / 豆沙粉 / 炭灰 / 午夜蓝，存在本地偏好里。
- 状态栏主题按钮左键循环切换，右键弹出带色块的选择菜单；设置页「通用 → 主题」列出同一份选项。切换主题时颜色平滑过渡，弹层有进出动画。
- 全部颜色走 CSS 变量（`--bg / --win / --pane / --side / --border / --fg* / --accent* / --s-*`）。
- 命名主题分两层：`data-theme` 决定明/暗基色，`data-tone` 只覆盖背景、边框、强调色等调色板；语法高亮沿用对应明/暗基色。
- 首屏在 JS 未执行前用 `prefers-color-scheme` 兜底，避免闪白。
- 代码块另有独立变量 `--code-bg` / `--code-border`，保证正文与代码块底色有差异。

## 编辑区背景

- 与全局主题独立：只作用于编辑器（正文、行号、查找面板），不影响侧栏、标签栏、AI 面板、状态栏。
- 预设：纸白、米黄、豆沙绿、雾灰、Solar 浅、Solar 深、Nord、炭灰、纯黑，另支持自定义颜色。
- 每个预设带 `tone`（light/dark），用于切换编辑器内的前景、语法色、行号色、代码块色等一整套变量。
- 选择「跟随主题」时使用全局主题的颜色。

## 字体与排版

- 正文字号 8–32px（默认 13）；状态栏字号按钮左键循环切换、右键弹菜单选择（13 标「默认」），弹层有进出动画；`Ctrl+滚轮` 也能缩放，屏幕中央 HUD 显示字号 1 秒。行高可调（默认 1.7），两者实时生效，编辑器不重建。
- 字体在状态栏字体按钮切换：左键循环、右键弹出带字体预览的选择菜单；设置 → 编辑器里保留同一份选项。可选默认（系统界面 + 等宽编辑器）/ 系统无衬线 / JetBrains Mono / Cascadia Code / Consolas / Fira Code / IBM Plex Mono / Maple Mono / 微软雅黑 / 思源黑体 / 更纱黑体 / 更纱等宽 / 思源宋体 / 霞鹜文楷 / 得意黑 / 未来荧黑。界面、源码、预览和大文件查看器一起生效。
- 预设只引用系统已安装字体，不打包字体文件；列表中的 JetBrains Mono、Cascadia Code、Fira Code、IBM Plex Mono、Maple Mono、思源黑体/宋体、更纱、霞鹜文楷、得意黑、未来荧黑均为 OFL 等免费/开源字体；Consolas 与微软雅黑为 Windows 自带字体。缺失时按备用字体回退。

## 透明度与层次

- 侧栏、标签栏用 `--side`，正文用 `--pane`，浮层用 `--win`，分隔线 `--border` / `--border-2`。
- 可点击控件保证足够对比度：不用低透明度「幽灵按钮」，操作优先用图标 + 边框。
- 悬浮提示统一由应用内 `TooltipLayer` 渲染：主题色卡片、箭头、阴影和 140ms 淡入，接管所有 `title`；不再使用浏览器默认提示样式。

## 已知待打磨

- 自定义背景色只有一个入口（编辑器背景），没有整套调色板管理。
- 语法高亮配色只区分明/暗，不随每套命名主题单独调色。
- 新增主题需要同时在 `global.css` 补一组 `data-tone` 变量和 `themes.ts` 的选项。
