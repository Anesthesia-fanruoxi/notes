# 标签页与导航

## 标签栏

- 每个标签显示：标题、临时标记、已修改点、关闭 ×。
- **顶部 2px 色条区分来源**：常驻文档蓝色（accent），临时文档琥珀色；选中时颜色加深。
- `+` 新建临时文件：立即在临时区落一个空文件并生成侧栏记录，标题 `未命名-N` 递增。
- 标签过多时横向滚动，最大宽度 230px，标题省略显示。

## 关闭

- `×`、`Ctrl+W`、鼠标中键都关闭当前/对应标签。
- **关闭不弹确认、不删内容**：
  - 常驻文档先补写 recovery 快照；
  - 临时文档先补写 scratch 副本；
  - 侧栏记录与文件都保留，随时可以重新打开。
- 关闭活动标签后自动切到相邻标签。

## 切换

- `Ctrl+Tab` / `Ctrl+Shift+Tab` 循环切换。
- 点侧栏文档、快速打开（`Ctrl+P`）、临时记录都能打开/激活对应标签。
- 同一文档不会开两个标签（常驻按 docId、临时按 tabId 判重）。

## 编辑状态

- 已修改：标签上的小圆点 + 状态栏「已修改」。
- 外部修改/文件丢失：编辑区顶部提示条（见《外部修改与文件删除》）。
- 降级模式：编辑区顶部黄色提示条（见《大文件降级》）。

## 窗口标题

- 应用窗口标题固定为 Note，不随文档变化。

## 已知待打磨

- 标签不可拖动排序、不能分屏。
- 关闭全部标签后没有「空白页」提示，只有初始的 `未命名-1`。
- 临时标签与常驻标签色条以外没有更多区分（如分组）。
