# Note 设计文档

本目录记录 Note（Tauri + React + CodeMirror 的本地笔记应用）的设计逻辑与现状实现，
面向打磨阶段：每条功能都写清楚**为什么这样设计、触发方式、数据落在哪、边界与已知问题**。

## 术语

- **正文 / 源文件**：磁盘上的真实文件。常驻文档指文档库里的 `docs/<docId>.<ext>`；临时文档指拖入的文件本身或临时区里的 `<tabId>.md`。
- **副本**：打开文档时在编辑器里编辑的那一份内容，所有手动编辑、AI 应用都只改副本。
- **快照 / 草稿**：副本的自动落盘产物。常驻文档写在 `recovery/<docId>.snap`，临时文档写在 `scratch/<tabId>.md`。用于关标签、退出后下次继续编辑。
- **版本**：显式保存过的历史（AI 修改前、还原前自动生成），位于 `versions/<docId>/`，可逐份还原。
- **记录**：侧栏「临时文档」里的一行，对应 `scratch/<tabId>.json` + `<tabId>.md`。

## 一条主线

> 打开 = 建副本；编辑只改副本；保存才覆盖正文；关标签/退出只丢视图，不丢副本；
> 删除入口集中在「侧栏 ×」与「文件丢失提示条」，且区分「删文件」和「只删记录」。

这条主线是 01 板块的核心，其余板块都围绕它展开。
