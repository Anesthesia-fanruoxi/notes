# 代码块与复制

## 渲染期形态

实时渲染下围栏代码块变成一个带头部条的整块：

```
┌───────────────────────────────┐
│ bash   [图标 复制]              │   ← 头部条，占原本隐藏的围栏行
├───────────────────────────────┤
│ firewall-cmd --permanent ...   │   ← 代码行（保留语法高亮）
└───────────────────────────────┘
```

- 起始围栏行被替换成「头部条」块级组件，不额外增高；结束围栏行仍留一行空白（已知问题）。
- 代码行加独立底色和左右描边，最后一行收底边与圆角。
- 光标进入代码块时，只有光标所在行退回源码，头部条仍在；光标停在起始围栏行时头部条让位给源码。

## 语言标识

- 取自围栏后面的标记（` ```shell ` → `shell`），原样显示。
- 悬浮显示完整名称：`js` → JavaScript、`sh/bash/shell` → Shell、`yml/yaml` → YAML 等；没写语言显示 `text`。
- 映射表在 `src/editor/livePreview.ts` 的 `LANG_LABELS`。

## 复制按钮

- 位置：语言标识右侧（6px 间距），图标 +「复制」文字，边框按钮，深浅主题都有足够对比度。
- 点击复制**代码正文**（不含围栏与语言标记），成功后变「✓ 已复制」1.2 秒；失败显示「复制失败」。
- `mousedown` 阻止默认行为，点按钮不会移动光标、不抢焦点。
- 剪贴板优先用 `navigator.clipboard`，不可用时退回隐藏 textarea + `execCommand`。

## 配色

- 使用独立变量 `--code-bg` / `--code-border`，与正文底色拉开距离：
  - 浅色：`#eef2f7` / `#dbe2ec`
  - 深色：`#2a2f38` / `#3f4653`
- 变量同时定义在全局主题与编辑器自定义背景（tone）里，切背景时一起变。

## 性能

- 头部条与按钮内容只依赖代码块快照；文档变化时整体重建装饰，3000 行以上直接关闭装饰。

## 已知待打磨

- 结束围栏仍占一行高度，代码块底部会多出一段空白。
- 超长代码块把按钮放在头部条左侧，不遮挡代码；早期「浮在右上角」的方案已废弃。
- 不支持代码块折叠、行号、语法高亮之外的增强（如 diff 染色）。
