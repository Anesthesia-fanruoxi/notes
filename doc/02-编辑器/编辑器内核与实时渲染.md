# 编辑器内核与实时渲染

## 内核

- 全应用只有一个 `EditorView`，切换标签时用 `view.setState(newState)` 换编辑器状态，避免反复销毁/重建。
- 每个标签的 `EditorState` 缓存在内存（`tabStates`），切回时保留光标、撤销栈、滚动位置（滚动位置按需恢复）。
- 正文永远留在 `EditorState` 里，不进 Zustand；store 只存元数据（标题、脏标记、编码、光标等）。

## Markdown 实时渲染（Typora 式）

- 仅对 `.md` / `.markdown` 生效，开关状态全局保存。
- 不是预览面板：在编辑区内把 Markdown 标记隐藏掉，光标所在行保持源码，方便继续输入。
- 支持：标题、引用、粗体/删除线/行内代码、链接、图片（仅 http(s) / data:image）、无序列表、任务列表、分隔线、表格、围栏代码块。
- 表格整块渲染成 HTML 表格；光标进入表格时整块退回源码。
- 超过 3000 行的文档自动关闭装饰，避免每次输入全量扫描。
- 装饰由 `StateField` 提供（CodeMirror 块级装饰的限制），只读文档内容，不修改文档、不影响撤销栈。

## 源码 / 渲染切换

- `Ctrl+Shift+V`，仅 Markdown 标签响应；其它文件不占用这个组合（保留纯文本粘贴）。
- 切换通过一个 `Compartment` 重配装饰与编辑器类，不重建 EditorState，撤销栈保留。
- 渲染态隐藏行号槽并加大正文左内边距；源码态恢复行号。

## 光标与状态同步

- 编辑器 update 监听只写元数据：光标行列、选区字符数、文档长度、脏标记、快照调度。
- 状态栏显示：临时/常驻、编码、换行、语言、行列、字符数、已修改、主题、字号、实时渲染开关、AI 入口。

## 已知待打磨

- 实时渲染的 Markdown 语法覆盖面有限（嵌套列表、引用内代码块等仍是纯文本）。
- 超大文档（>3000 行）没有提示「已关闭实时渲染」，只在行为上静默降级。
