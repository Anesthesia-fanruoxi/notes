# 查找替换

## 入口

- `Ctrl+F`（查找）/ `Ctrl+H`（替换）→ 打开 CodeMirror 自带搜索面板。
- 编辑器处于输入法组合（`view.composing`）时一律放行，避免抢输入。

## 面板

- 使用 `@codemirror/search` 的 `search` + `openSearchPanel`，不做自研 UI。
- 面板贴在编辑器顶部，样式与整体主题一致（输入框、按钮、勾选项都走 CSS 变量）。
- 支持：区分大小写、整词匹配、正则表达式。
- 命中高亮：普通命中琥珀色，当前选中命中加深。
- 关闭：面板的 × 或 `Esc`。

## 与全局快捷键的关系

- App 层 window keydown 与 CodeMirror keymap 两处都注册了查找，确保焦点不在编辑器时也能打开面板。
- 全局处理会在 `closePrompt` 等弹层出现时让路，避免在确认框后面触发。

## 已知待打磨

- 只有「当前文件」查找；文档库全文搜索尚未实现（PROMPT 里列在二期）。
- 替换不需要二次确认，误操作依赖撤销栈。
