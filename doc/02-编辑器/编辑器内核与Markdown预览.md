# 编辑器内核与 Markdown 预览

## 内核

- 全应用只有一个 `EditorView`，切换标签时用 `view.setState(newState)` 换编辑器状态，避免反复销毁/重建。
- 每个标签的 `EditorState` 缓存在内存（`tabStates`），切回时保留光标、撤销栈、滚动位置（滚动位置按需恢复）。
- 正文永远留在 `EditorState` 里，不进 Zustand；store 只存元数据（标题、脏标记、编码、光标等）。

## Markdown 预览（只读）

- 仅对 `.md` / `.markdown` 生效，开关状态全局保存。
- 不是独立预览面板：在编辑区内隐藏 Markdown 标记，渲染成只读视图；编辑统一走源码模式。
- 预览态通过 `EditorState.readOnly` 锁定正文，仍可选中、复制；代码块头部的复制按钮可用。
- 支持：标题、引用、粗体/删除线/行内代码、链接、图片（仅 http(s) / data:image）、无序列表、任务列表、分隔线、表格、围栏代码块。
- 表格始终整块渲染成 HTML 表格，单元格内的加粗等行内语法会一起渲染；不提供单元格编辑。
- 代码块围栏渲染成头部/底部条，语言标识只读，复制按钮复制代码正文。
- 超过 3000 行的文档自动关闭装饰，避免每次输入全量扫描。
- 装饰由 `StateField` 提供（CodeMirror 块级装饰的限制），只读文档内容，不修改文档、不影响撤销栈。

## 源码 / 预览切换

- `Ctrl+Shift+V`，仅 Markdown 标签响应；其它文件不占用这个组合（保留纯文本粘贴）。
- 切换通过一个 `Compartment` 重配只读标记、装饰与编辑器类，不重建 EditorState，撤销栈保留。
- 预览态隐藏行号槽并加大正文左内边距；源码态恢复行号并允许编辑。
- 切换时会把同一份 selection 带进重配事务，强制触发 `selectionSet`，让多行选区在预览布局下仍然可见。

## 光标与状态同步

- 编辑器 update 监听只写元数据：光标行列、选区字符数、文档长度、脏标记、快照调度。
- 状态栏显示：临时/常驻、编码、换行、语言、行列、字符数、已修改、主题、字号、预览开关、AI 入口。

## 已知待打磨

- 预览的 Markdown 语法覆盖面有限（嵌套列表、引用内代码块等仍是纯文本）。
- 超大文档（>3000 行）没有提示「已关闭预览」，只在行为上静默降级。
- 预览态是只读的，所有编辑操作需要切回源码模式。
