# 编辑器内核与 Markdown 预览

## 内核

- 可编辑的 `EditorView` 只有一个，切换标签时用 `view.setState(newState)` 换编辑器状态，避免反复销毁/重建。
- Markdown 预览是第二个只读 `EditorView`：源码视图负责编辑，预览视图只负责渲染。
- 每个标签的 `EditorState` 缓存在内存（`tabStates`），切回时保留光标、撤销栈、滚动位置（滚动位置按需恢复）。
- 正文永远留在 `EditorState` 里，不进 Zustand；store 只存元数据（标题、脏标记、编码、光标等）。
- 列选择：编辑区 `Alt / Option`（或 `Ctrl`）+ 拖动矩形选择，每行一个选区，可整列插入/替换；普通点击、`Esc`、普通方向键退出列模式回到单光标。多光标依赖 `EditorState.allowMultipleSelections.of(true)`。
- 未保存改动：以源文件（库内正文 / 磁盘原文件）为基线对比当前快照，行号后显示琥珀色竖条；悬停该行显示修改前 / 修改后内容。保存或重载后基线推进、标记清空；新建且无源文件的文档基线为空。超过 2MiB 或 5 万行的文档不做追踪（只读文件不会创建快照）。

## Markdown 预览（只读）

- 按有效语言判定：文件名是 `.md` / `.markdown`，或手动把语言切到 Markdown，都支持预览；手动切成非 md 语言时自动收起预览。
- 保存时按当前语言同步后缀：库内文档重命名正文文件并更新索引，磁盘临时文件在同目录改后缀；目标后缀已存在时保留原文件并提示。标题尾部带旧后缀时一起替换。
- 收起预览保留约 1s 的折叠 / 淡出动画，源码栏同步展开；开关状态全局保存。
- 代码模式：左右分栏，左侧源码实时编辑，右侧实时只读渲染，两栏等宽；两侧按文档位置双向同步滚动。
- 表格是整块 widget：同步滚动会按源码行映射到表格 DOM 行，滚动长表格时两侧也能持续跟随；顶部/底部会吸附对齐，避免一边到底另一边还差一截。
- 预览模式：收起左侧编辑栏，左侧显示 Markdown 目录（标题层级、点击平滑跳转、随预览滚动高亮），右侧预览占满剩余宽度；从代码模式切到预览时目录从左侧滑入并与预览拼接。
- 目录按标题层级生成树：左键跳转，右键或左侧方框 +/− 折叠/展开（带高度缓动）；子级缩进带对齐线，父级标题在目录滚动时吸顶保留。
- 目录默认 260px（至少容纳 3 级标题），可拖右边缘在 180–420px 间调整，宽度持久化；双击边缘恢复 260px。
- 预览视图通过 `EditorState.readOnly` 锁定正文，仍可选中、复制、查找；代码块头部的复制按钮可用。
- 文档同步：源码视图逐笔修改把同一份 `changes` 应用到预览，保留预览滚动位置；切标签、外部重载、版本还原等整篇替换时整篇对齐。
- 预览视图同样按 Markdown 解析，代码块内部保持与源码一致的语法配色。
- 支持：标题、引用、粗体/删除线/行内代码、链接、图片（仅 http(s) / data:image）、无序列表、任务列表、分隔线、表格、围栏代码块。
- 表格始终整块渲染成 HTML 表格，单元格内的加粗等行内语法会一起渲染；不提供单元格编辑。
- 代码块围栏渲染成头部/底部条，语言标识只读，复制按钮复制代码正文。
- 超过 3000 行的文档自动关闭装饰，避免每次输入全量扫描。
- 装饰由 `StateField` 提供（CodeMirror 块级装饰的限制），只读文档内容，不修改文档、不影响撤销栈。

## 源码 / 预览切换

- `Ctrl+Shift+V`，仅 Markdown 标签响应；其它文件不占用这个组合（保留纯文本粘贴）。
- 切换只控制左侧源码栏的显隐与预览栏宽度，不重建任何 EditorState，撤销栈保留。
- 源码 ↔ 预览切换带约 1 秒的左栏折叠/展开动画（flex-grow + 透明度），预览栏同步伸缩；收起结束后左栏退出可见与焦点。
- 预览模式隐藏左侧编辑栏，预览占满整宽；代码模式恢复左侧编辑栏，左右各占一半。
- 预览视图不显示行号与活动行；正文左内边距加大，选区和代码块样式保持一致。
- 切换后焦点交给当前可见的一侧；预览态下 `Ctrl+F` 在预览视图里查找。
- 大文件降级（lite / plain 档）不挂预览视图，切预览时仍显示源码。

## 光标与状态同步

- 源码编辑器的 update 监听只写元数据：光标行列、选区字符数、文档长度、脏标记、快照调度，并把文档变化同步给预览视图。
- 预览视图不参与正文读取、AI 上下文与保存，这些仍走唯一的可编辑视图。
- 状态栏显示：临时/常驻、编码、换行（左键循环、右键列表，LF / CRLF / CR 整篇转换，保存时生效）、语言、行列、字符数、已修改、主题、字号、预览开关、AI 入口。

## 已知待打磨

- 预览的 Markdown 语法覆盖面有限（嵌套列表、引用内代码块等仍是纯文本）。
- 超大文档（>3000 行）没有提示「已关闭预览」，只在行为上静默降级。
- 预览态是只读的，所有编辑操作需要在代码模式的左栏完成。
