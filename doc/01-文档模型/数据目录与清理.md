# 数据目录与清理

所有数据都在本机，不联网同步（AI 请求除外）。

## 应用数据目录

Windows：`%APPDATA%\com.notelib.app`

```
com.notelib.app/
├── library-path.txt      # 文档库当前位置（迁移过才有意义）
├── .window-state.json    # 窗口大小/位置/最大化（tauri-plugin-window-state）
├── library/              # 文档库根目录（可迁移到别处）
│   ├── index.json        # 分类树 + 文档元数据（标题、分类、扩展名、AI 可读、大小）
│   ├── docs/             # 正文：<docId>.<ext>
│   ├── chats/            # 每篇文档的 AI 会话 json
│   └── versions/         # 版本快照：<docId>/<ts>.snap
├── recovery/             # 常驻文档的未保存草稿：<docId>.snap
├── scratch/              # 临时文档副本与记录：<tabId>.md + <tabId>.json
└── usage/                # AI 用量：usage-YYYY-MM.jsonl（按月分文件）
```

- `recovery/`、`scratch/`、`usage/` 始终留在应用数据目录，不随库迁移、不进备份。
- 文档库位置记录在 `library-path.txt`；迁移后旧库默认保留不删。

## 清理策略

| 目录 | 策略 |
| --- | --- |
| `recovery/` | 总量超过 100MB 时按最旧优先删除（启动时自检） |
| `versions/` | 每篇保留最近 20 份；总量超 200MB 按最旧清理 |
| `usage/` | 只保留最近 12 个月（启动时删除更早的月文件） |
| `scratch/` | 不自动清理：只有用户点侧栏 `×` 或保存进库时才删除 |
| `.window-state.json` | 随窗口变化防抖写入，下次启动自动恢复 |

## 备份 / 恢复 / 迁移（设置页「文档库」）

- **备份**：把整个 `library/` 复制到用户选择目录下的 `NoteLibrary-<时间戳>`，复制完读一次索引做校验。
- **恢复**：先校验备份索引；把当前库另存为 `library.bak-<时间戳>` 兜底，再整体覆盖；要求重启以刷新内存状态。
- **迁移**：复制到 `<新目录>/NoteLibrary`（目标必须为空目录），校验通过后写 `library-path.txt` 切换指向，旧库保留。

## 边界

- 直接删除应用数据目录等于清空所有草稿与记录，正文如果迁移过则不受影响。
- 没有任何云同步；多台设备之间需要手动搬运文档库。
