# 服务商与模型

设置页「AI」分区，所有改动先进草稿，点对话框右下角「保存」统一落盘。

## 服务模板（两个标签页）

| 标签页 | 内容 |
| --- | --- |
| 常用服务商 | DeepSeek、通义千问、GLM Token Plan CN、Kimi Token Plan CN、MiMo Token Plan CN、Agnes、本地 Ollama |
| 自定义服务商 | 只支持 OpenAI 兼容协议，Base URL / 模型由用户自己填 |

- 常用服务商：Base URL **只读**（置灰），右侧「复制」按钮；地址固定，想改就切自定义。
- 切到自定义：Base URL 变为可编辑，保留当前地址/模型当起点。
- 切换模板会填入该服务的 Base URL 与默认模型；`+` 之外的 Key 按服务商分别存放。

## API Key

- 只存 Windows 凭据管理器（Rust `keyring`，service 名 = 应用 id，账号 = `ai-key-<provider>`）。
- 前端只持有「是否已配置」的布尔值，Key 永不进 localStorage / Zustand / 日志。
- 输入框无独立保存/清除按钮：填好后点右下角「保存」一并写入；模型拉取时未保存的 Key 只在本次请求里临时传给 Rust，不落库。

## 模型列表

- 点模型输入框（聚焦或点击）自动请求 `GET {Base URL}/models`，带已保存或刚输入的 Key。
- 目录层级用 Rust 命令完成，Key 不出 Rust；接口不认 `stream_options` 之类的字段不影响这里。
- 结果用自绘下拉（portal 渲染，不会被设置页滚动区裁切），按字母排序；点一项即选中，也可手动输入。
- 同一「模板 + 地址」只成功拉一次；改地址或换模板会清空缓存；失败后点一下可重试。
- 前置校验做成提示：没填 Base URL、没保存 Key 分别给出对应文案。

## 计费

- 每个服务商单独配置：输入 / 输出 / 缓存命中，单位「元 / 百万 tokens」。
- 只用于「用量」页估算费用，不影响请求；全 0 表示不计费用；缓存命中价留空按输入价算。

## 已知待打磨

- 预置地址硬编码在前端，服务商改价/改版需要发版。
- MiMo / Agnes 默认模型为空，首次使用需要先拉取模型。
- 没有「测试 Key 是否有效」的独立按钮，只有整模型请求的「测试连接」。
