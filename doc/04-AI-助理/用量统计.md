# 用量统计

设置页「用量」分区，展示每次 AI 调用的 tokens、缓存命中、耗时、费用与提示词。

## 数据采集

- 每次对话成功后，Rust 端把一条记录追加到 `appdata/usage/usage-YYYY-MM.jsonl`（按月分文件）。
- 请求带 `stream_options.include_usage`；个别网关不认这个字段时自动去掉重试一次。
- 从响应的 `usage` 解析：
  - `prompt_tokens` / `completion_tokens` / `total_tokens`
  - `prompt_cache_hit_tokens`、`prompt_cache_miss_tokens`（DeepSeek 等）
  - `prompt_tokens_details.cached_tokens`（OpenAI 等）
- 供应商不返回 usage 时仍记一行（tokens 为 0），保留提示词与耗时，便于回看。

## 记录字段

| 字段 | 说明 |
| --- | --- |
| ts | 调用完成时间（毫秒） |
| provider / model | 服务商标识与模型名 |
| docId / docTitle | 文档 id 与标题（临时文档为标题） |
| promptTokens / completionTokens / totalTokens | 用量 |
| cacheHitTokens / cacheMissTokens / cachedTokens | 缓存命中情况 |
| durationMs | 请求耗时 |
| promptPreview | 最后一次用户提示词前 500 字 |

## 保留与清理

- 只保留最近 12 个月：启动时删除更早的月文件。
- 一天几十次调用也只有几十 KB，不需要数据库。

## 面板

- 三张卡片：今日 / 本月 / 最近 12 个月 —— tokens、调用次数、输入/输出、缓存命中率、费用。
- 柱状图：按日（30 天）/ 按周（12 周）/ 按月（12 个月）切换，输入/输出堆叠，悬浮看明细。
- 明细表：时间、模型、输入、输出、缓存命中、耗时、费用；点行展开提示词与文档名；分页加载（每页 50 条）。
- 聚合与分桶在前端按本地时区计算，Rust 只提供原始记录。

## 费用公式

```
命中 = min(cacheHitTokens, promptTokens)
未命中 = promptTokens - 命中
费用 = (未命中 × 输入价 + 命中 × (缓存命中价 || 输入价) + completionTokens × 输出价) / 1_000_000
```

没配单价时费用显示 `—`，面板提示「在 AI 页填计费后这里会显示费用」。

## 已知待打磨

- 只统计 `ai_chat`，模型列表、连接测试不计入。
- 取消的请求若没有 usage，会以 0 tokens 记录一行，可能轻微抬高「调用次数」。
- 提示词只保留前 500 字，长上下文无法完整回溯。
- 没有导出 CSV / 按服务商筛选用量的入口。
