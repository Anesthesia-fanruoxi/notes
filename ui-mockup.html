# 编码与换行
> 用户没主动改，写回就必须和读入完全一致。
## 探测顺序
1. 先看 BOM：UTF-8 / UTF-16LE / UTF-16BE
2. 无 BOM 用 chardetng 猜，再实际解码验证
3. 出现替换字符 U+FFFD 就回退 GB18030 → UTF-8
4. 换行符取多数，混合时单独记录
保存时不要动原编码，这是红线：
```ts
const doc = await read_text_file(path)
// 原样带回去，不做任何转换
await write_text_file(path, doc.content, {
encoding: doc.encoding,
lineEnding: doc.lineEnding,
})
```
**结论**：编码是文件的属性，不是编辑器的偏好。
